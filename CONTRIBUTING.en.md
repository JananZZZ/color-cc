# Contributing to color-cc

Thank you for your interest! 🎉

## 🚀 Getting Started

### Fork and Clone

1. Fork the repository
2. Clone your fork:
   ```bash
   git clone https://github.com/your-username/color-cc.git
   cd color-cc
   ```

### Make Changes

1. Create a feature branch:
   ```bash
   git checkout -b feat/amazing-feature
   ```

2. Make your changes and test locally

3. Commit changes:
   ```bash
   git commit -m "Add amazing feature"
   ```

4. Push to your fork:
   ```bash
   git push origin feat/amazing-feature
   ```

### Pull Request

1. Open a Pull Request on GitHub
2. Fill in the PR template
3. Wait for review

## 📋 Development Guidelines

### Code Style

- Keep scripts simple and readable
- Use meaningful variable names
- Add comments for complex logic
- Test on both Windows and Unix when possible

### Theme Guidelines

When creating new themes:
- Use the cosmic color palette for consistency
- Keep it to 4 lines maximum
- Test with different Claude Code models
- Include a screenshot in your PR

### Testing

- Test the install scripts on a fresh machine
- Verify all dashboard metrics display correctly
- Check cc-switch integration (if applicable)

## 🐛 Reporting Issues

When reporting bugs, please provide:

- **OS and version**: Windows 11 / macOS 14 / Ubuntu 22.04
- **Claude Code version**
- **Error messages**: Copy any error output
- **Steps to reproduce**: What you did before the issue
- **Screenshots**: If the issue is visual

## 💡 Feature Requests

We welcome feature requests! Please:

1. Check existing issues first
2. Describe the use case clearly
3. Explain why it would be useful
4. Consider if it fits the project's scope

## 📜 Code of Conduct

Be respectful, inclusive, and constructive. We're all here to make Claude Code better.

## 🙏 Thank You

Every contribution helps! Whether it's a bug fix, new feature, documentation, or just spreading the word.
